#  Linux 基础阶段总结

本文档基于学习笔记整理，涵盖了 Linux 基础操作的核心知识点，分为**文件与权限**、**进程与系统**、**网络与软件**

---

##  一、 文件与权限

### 1. 目录与文件基础操作

*   **`ls`**：列出目录下的内容。
    *   `-a`：显示所有内容（包含隐藏文件）。
    *   `-l`：竖向排列展示详情。
    *   `-h`：显示文件大小（必须与 `-l` 一起使用，如 `ls -lh`）。
    *   `-al`：以上参数相加。
*   **`pwd`**：查看当前工作目录的绝对路径。
*   **`cd`**：切换目录。
    *   绝对路径：从根目录 `/` 开始写。
    *   相对路径：从当前目录开始写。
    *   `.`：当前目录。
    *   `..`：上一级目录。
    *   `~`：HOME目录（默认不加参数 `cd` 也是回到 HOME）。
*   **`mkdir [-p]`**：创建文件夹。
    *   `-p`：一次性创建多个层级目录（递归创建）。
*   **`touch`**：在指定位置创建空文件。

### 2. 文件查看与编辑

*   **`cat`**：查看文件全部内容（适合小文件）。
*   **`more`**：分页查看文件内容（一页一页看，适合大文件）。
*   **`tail [-f -num]`**：查看文件尾部内容。
    *   `-num`：查看尾部多少行（默认10行，如 `-n 3`）。
    *   `-f`：持续跟踪文件的最新更改（常用于查看日志）。
*   **`vim`**：文本编辑器。
    *   **命令模式** (默认) -> **输入模式** (按 `i, a, o` 等) -> **底行模式** (按 `:`)。
    *   *快捷输入*：`i` (当前光标前), `a` (当前光标后), `I` (行首), `A` (行尾), `o` (下一行), `O` (上一行)。
    *   *搜索*：`/关键词` 向下搜索，`n` 查找下一个，`N` 查找上一个。
    *   *删除/复制*：`ndd` (删除n行), `nyy` (复制n行), `p` (粘贴), `u` (撤销)。
    *   *快速删除*：`dG` (向下全删), `dgg` (向上全删), `d$` (删到行尾), `d0` (删到行首)。

### 3. 文件复制、移动与删除

*   **`cp [-r] 参数1 参数2`**：复制文件或文件夹。
    *   参数1：源文件；参数2：目标位置。
    *   `-r`：递归复制，用于文件夹。
*   **`mv 参数1 参数2`**：移动文件或文件夹（也可用于重命名）。
    *   若参数2不存在，则将参数1重命名为参数2。
*   **`rm [-r -f] 参数...`**：删除文件或文件夹。
    *   `-r`：递归删除文件夹。
    *   `-f`：强制删除（不提示）。
    *   *通配符 `*`*：`test*` (test开头), `*test` (test结尾), `*test*` (包含test)。

### 4. 文本搜索与统计

*   **`find 起始路径 -name "被查找名"`**：按名称搜索文件。
    *   `find 起始路径 -size +|-n[KMG]`：按文件大小搜索（`+` 大于, `-` 小于）。
*   **`grep [-n] 关键字 文件路径`**：在文件内搜索关键字。
    *   `-n`：显示匹配的行号。
*   **`wc [-c -m -l -w] 文件路径`**：统计文件内容。
    *   `-c`：统计字节数；`-m`：统计字符数；`-l`：统计行数；`-w`：统计单词数。

### 5. 输出与重定向

*   **`echo "内容"`**：在命令行输出指定内容（复杂内容用双引号包围）。
*   **反引号 `` ` ``**：被包围的内容会作为命令执行（如 ``echo `pwd` ``）。
*   **重定向符**：
    *   `>`：将左侧命令结果**覆盖**写入右侧文件。
    *   `>>`：将左侧命令结果**追加**写入右侧文件。

### 6. 权限管理

*   **权限类型**：`r` (读/4), `w` (写/2), `x` (执行/1), `-` (无/0)。
*   **`ls -l` 信息解读**：`-` (文件) / `d` (文件夹)，后面紧跟 3组权限（所属用户、所属用户组、其他用户）。
*   **`chmod [-R] 权限 文件/文件夹`**：修改文件/文件夹权限。
    *   数字序号法：`chmod 777 文件`（分别代表所有者、组、其他）。
    *   `-R`：对文件夹内所有内容递归应用。
*   **`chown [-R] [用户]:[用户组] 文件/文件夹`**：修改所属用户和用户组（**仅限 root 用户**）。
    *   `-R`：递归操作。

##  二、 进程与系统

### 1. 命令查找与管道

*   **`which 要查找的命令`**：查看命令的程序文件存放位置。
*   **`|` (管道符)**：将左边命令的结果，作为右边命令的输入（常配合 `grep` 使用）。

### 2. 用户与用户组管理

*   **`su - [用户名]`**：切换账户（`exit` 退回到上一个用户）。
*   **`groupadd 用户组名`**：创建用户组。
*   **`groupdel 用户组名`**：删除用户组。
*   **`useradd [-g -d] 用户名`**：创建用户。
    *   `-g`：指定用户组（不指定会创建同名组并自动加入）。
    *   `-d`：指定 HOME 路径（默认 `/home/用户名`）。
*   **`userdel [-r] 用户名`**：删除用户（`-r` 同时删除 HOME 目录）。
*   **`id [用户名]`**：查看用户所属组。
*   **`usermod -aG 用户组 用户名`**：修改用户所属组（追加）。
*   **`getent passwd`**：查看当前系统中所有用户信息。

### 3. 终端快捷键

*   **`Ctrl + c`**：中止进程（强制停止当前程序）。
*   **`Ctrl + d`**：退出账户或特定页面。
*   **`history`**：查看历史命令。
*   **`Ctrl + a`**：光标跳到行首。
*   **`Ctrl + e`**：光标跳到行尾。
*   **`Ctrl + 左/右`**：按单词左右跳转。
